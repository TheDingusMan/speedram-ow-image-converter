# speedram-ow-image-converter
Image converter for Speedram Ow

Choose a background color (it HAS to be a color that is not in the image you are importing into the converter), then press space to continue. Import your image and decide how big it should be, then wait until the image list shows up. Export the list as a .txt file, and your image has now been converted into a list for Speedram Ow to render. It's that simple!

You can also hit ` to reset
